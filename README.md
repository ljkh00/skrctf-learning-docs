# SKRCTF Learning Docs

Participant guide for [SKRCTF](https://skrctf.me), a free cybersecurity Capture-the-Flag (CTF) learning platform.

**Live site:** https://ljkh00.github.io/skrctf-learning-docs/

## Who this is for
New and returning SKRCTF players who want to go from first login to solving challenges on their own.

## What's inside
| Section | Purpose |
|---|---|
| Onboarding | Account, first flag, tools |
| Pathways | Where to start and what to do next |
| Insights | What player data says about how people learn on SKRCTF |
| Contributing | Style guide and templates for writers |

## Contributing
Docs are written in Markdown and published with MkDocs. Open a pull request; follow the [style guide](docs/contributing/style-guide.md).

Platform engine (admin/deployment docs) lives in a separate repo: [Custom-CTFd-Engine](https://github.com/ljkh00/Custom-CTFd-Engine).
