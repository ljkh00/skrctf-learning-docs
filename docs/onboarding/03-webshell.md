# 3. Use the webshell

**Goal:** run Linux commands in your browser. **Time:** 10 minutes.

Some challenges need a Linux terminal. SKRCTF gives you one in the browser, so you do not need to install anything.

1. Open **Webshell** from the menu.
2. Log in with the **GROUP** credentials shown on your profile page.
3. Try these commands:

| Command | What it does |
|---|---|
| `ls` | List files |
| `cat file.txt` | Show a file's contents |
| `nc host port` | Connect to a challenge server |

**Done when:** `ls` runs without errors.
