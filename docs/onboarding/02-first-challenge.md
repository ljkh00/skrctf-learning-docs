# 2. Solve your first challenge

**Goal:** submit one correct flag. **Time:** 15 minutes.

## What is a flag?
A flag is a secret string hidden inside a challenge. It usually looks like `7h1s_15_7h3_Fl@g`. Finding it proves you solved the challenge. However, you need to submit the flag as `SKR{7h1s_15_7h3_Fl@g}` across SKRCTF unless specified.

## Steps
1. Open **Challenges** and choose the **Warm up** category.
2. Pick the challenge with the lowest difficulty. Challenges are ordered from easiest to hardest.
3. Read the description and download any attached file.
4. Find the flag and paste it exactly into the box, then select **Submit**.

!!! warning "Common mistakes"
    - Extra spaces before or after the flag
    - Wrong capital letters — flags are case-sensitive
    - typo errors - I vs l vs 1, 0 vs O
    - Sharing flags: some flags are unique per player, so a copied flag will not work

**Done when:** the challenge shows as solved.

After solving, read other players' write-ups for that challenge to see different approaches.
