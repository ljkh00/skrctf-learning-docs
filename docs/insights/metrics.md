# What the data says

These findings shape how SKRCTF's learning pathways are ordered.

**Source:** Khoo, L. J. et al. (2024). *Analyzing Performance Patterns and User Experience in Online Cybersecurity Challenges: Insights from SKRCTF.* International Journal of Multimedia & Its Applications, 16(6), 1–12. Study of 120 learners (aged 19–30) across 127 challenges, 2024 cohort.

## Completion rate by category
| Tier | Category | Completion |
|---|---|---|
| Entry | OSINT | 83.3% |
| Entry | Warm up | 54.5% |
| Entry | Forensics | 47.2% |
| Entry | Linux | 44.6% |
| Intermediate | Steganography | 35.4% |
| Intermediate | Cryptography | 33.5% |
| Intermediate | Web | 29.8% |
| Intermediate | Binary | 29.2% |
| Advanced | Misc | 14.2% |
| Advanced | Programming | 12.5% |

**Design decision:** the [Beginner pathway](../pathways/beginner.md) starts with entry-tier categories.

## Analytical before technical
| Challenge type | Average completion |
|---|---|
| Analytical (Forensics, OSINT, Crypto, Stego) | 46.7% |
| Mixed (Warm up, Linux, Mini games, Misc) | 36.7% |
| Technical (Web, RE, Binary, Programming) | 28.0% |

**Design decision:** analytical challenges are the entry point; technical ones come later with more guidance.

## More attempts is not always better
Players with 101–150 attempts had the highest completion rate (52.1%). Beyond that, extra attempts added little.

**Design decision:** docs encourage regular, measured practice instead of grinding.

## Hard does not mean quit
Perceived difficulty correlated negatively with score (r = −0.421). But players who rated challenges "very challenging" made more attempts (107 on average) than those who found them easy (73).

**Design decision:** docs label difficulty honestly and normalise being stuck.

## Limits
Single cohort, self-reported difficulty, no long-term follow-up.
