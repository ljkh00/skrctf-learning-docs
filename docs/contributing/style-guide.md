# Style guide

Rules for anyone writing SKRCTF learning docs.

## Every page
- Opens with **Goal** and **Time** (or **Who**).
- Ends with **Done when** and a **Next** link.
- One task per page.

## Writing
- Plain English. Short sentences, under 25 words.
- Second person ("you"), active voice.
- Explain a term the first time it appears.
- Never give away a flag or a full solution in onboarding pages.

## Formatting
- Numbered lists for steps, tables for comparisons.
- Code and commands in `backticks`.
- Use admonitions: `tip` for advice, `warning` for common mistakes.

## Claims
- Any number must cite its source.

## Review
Every change goes through a pull request and one review before merge.
