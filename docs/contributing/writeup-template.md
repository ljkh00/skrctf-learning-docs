# Write-up template

Copy this when sharing how you solved a challenge.

```markdown
# <Challenge name>

**Category:** <e.g. Forensics>  **Difficulty:** <Easy / Medium / Hard>

## What the challenge gives you
<Files, links or description in one or two lines>

## Approach
1. <First thing you tried and why>
2. <What worked>

## Tools used
- <tool> — <what for>

## What I learned
<One or two lines>
```

Do not paste the flag itself.
